## 报文计算公式

```
帧：[0x55][0xAA][CTRL=0x01][V_H][V_L][W_H][W_L][CKSUM]
CKSUM = (0x01 + V_H + V_L + W_H + W_L) & 0xFF
V = velocity_v (int16 大端), front_speed = V/1000.0 (clamp[-1,1])
W = velocity_w (int16 大端), turn_omega  = W/1000.0 (clamp[-1,1])
```

## 速算工具函数（Python快速验算用）
```python
def frame(V, W):
    data = bytes([0x55, 0xAA, 0x01,
                  (V >> 8) & 0xFF, V & 0xFF,
                  (W >> 8) & 0xFF, W & 0xFF])
    cksum = (0x01 + data[3] + data[4] + data[5] + data[6]) & 0xFF
    return data.hex().upper() + f" CKSUM={cksum:02X} → {data.hex().upper()}{cksum:02X}"

# 示例：
# frame(500, 0)   → 55AA0101F40000 CKSUM=F6 → 55 AA 01 01 F4 00 00 F6
# frame(1000, 0)  → 55AA0103E80000 CKSUM=EC → 55 AA 01 03 E8 00 00 EC
```

## 七、RPi 超时自动站立（7 用例）⭐⭐ 新增功能

> 测试前提：遥控器切至 RPi 模式（sw5=0x0320, sw8=0x0000）
> 超时阈值：500ms
> 状态映射：case 2=行走，case 12=RPi 站立，case 4=遥控站立

### T7.1 正常行走 → 停发 → 超时站立（核心路径）

| 步骤 | 操作 | 期望 |
|------|------|------|
| 1 | 遥控切 RPi 模式 | `temp_state=12`（无数据，站立） |
| 2 | Python 脚本 C 循环发送 | `temp_state=2`，`front_speed` 跟随变化 |
| 3 | Ctrl+C 停止发送 | `front_speed=0`，`uart8_walk_request=1` 保持 |
| 4 | 等待 **500ms** | `uart8_walk_request→0`，`temp_state→12`，狗站立 |
| ✅ | |

### T7.2 站立后恢复发送 → 自动回到行走

| 步骤 | 操作 | 期望 |
|------|------|------|
| 1 | T7.1 结束后（站立状态） | `temp_state=12` |
| 2 | 重新 Python C 循环发送 | 收到第一帧 → `uart8_walk_request=1` → `temp_state=2` |
| 3 | 持续发送 | `front_speed` 正常跟随，狗行走 |
| ✅ | |

### T7.3 持续发送 (0,0) 速度 → 保持行走（不误触发站立）

| 步骤 | 操作 | 期望 |
|------|------|------|
| 1 | Python 发 `55 AA 01 00 00 00 00 01` 循环 | `front_speed=0.0` |
| 2 | 持续发送 10 秒 | `temp_state=2`（**一直是 2，不切 12**） |
| 3 | 停止发送 | 500ms 后 `temp_state→12` |
| ✅ | |

> 说明：只要树莓派持续在发数据（哪怕 V=W=0），`uart8_walk_request` 保持 1，
> 不会触发超时站立。只有真正停止发送 >500ms 才会站立。

### T7.4 遥控切出 RPi 模式 → 状态自动退出

| 步骤 | 操作 | 期望 |
|------|------|------|
| 1 | RPi 行走中（`temp_state=2`） | 正常 |
| 2 | 遥控切 sw8≠0x0000 | 第 279 行不匹配 → `temp_state` 由遥控决定 |
| 3 | 切回 RPi 模式 | `temp_state = uart8_walk_request ? 2 : 12` |
| ✅ | |

### T7.5 遥控独立站立不受 RPi 超时影响

| 步骤 | 操作 | 期望 |
|------|------|------|
| 1 | 遥控切站立（sw5=0x0000, sw7=0x0320） | `temp_state=4` |
| 2 | Python 发数据或停止 | `temp_state` **始终 4**，不受 RPi 数据影响 |
| 3 | 切回 RPi 模式 | 正常工作 |
| ✅ | |

### T7.6 上电后直接进 RPi 模式 → 无数据时应站立

| 步骤 | 操作 | 期望 |
|------|------|------|
| 1 | MCU 上电，遥控直接切 RPi 模式 | `last_rx_tick=0`，`uart8_walk_request=0` |
| 2 | 不发任何数据 | `temp_state=12`（站立，**不会**上电 500ms 误触发） |
| 3 | 开始发数据 | `temp_state→2`，正常 |
| ✅ | |

> 验证 `last_rx_tick != 0u` 保护逻辑正确。

### T7.7 短暂丢帧不触发站立（< 500ms）

| 步骤 | 操作 | 期望 |
|------|------|------|
| 1 | Python 50ms 循环发送 | `temp_state=2` |
| 2 | 暂停 200ms（< 500ms 阈值） | `temp_state` **保持 2** |
| 3 | 恢复发送 | 正常 |
| 4 | 暂停 600ms（> 500ms 阈值） | `temp_state→12` |
| ✅ | |

> 验证超时阈值精度。
